Přepni na main a stáhni poslední změny — příprava před zahájením nového úkolu.

```bash
git checkout main && git pull origin main
```

Vypiš aktuální stav:
- aktuální branch (měl by být `main`)
- poslední 3 commity

Novou branch pro konkrétní úkol vytvoř až podle zadání:
`git checkout -b [type/popis]` — kde `type` je `feature/`, `fix/`, `content/[slug]` apod.
